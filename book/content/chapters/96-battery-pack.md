# Optional: using the battery pack


Per default, the robot uses four AA batteries. However, the robot can also be powered using a rechargeable battery pack. This battery pack allows the robot to be charged using a USB cable. Here, we show how to install the battery pack if you choose to use it.

![The battery pack.](images/optional-using-the-battery-pack-b3a67c4f.jpg)

![](images/optional-using-the-battery-pack-4f020b9a.jpg)

Start by removing the AA battery holder from the robot. It might be easier to unscrew the robot’s top board, as shown in the picture. You will have to unscrew the board in the next step.

 

![](images/optional-using-the-battery-pack-db21ceea.jpg)

If you haven’t unscrewed the robot’s board, please do so for this step. The battery pack attaches to the bottom of the robot’s board. It clips into the slots at the bottom of the board. Next, plug the robot pack into the robot (see the black and red cables in the image). The plug has slots that ensure it only fits one way into the robot.

![](images/optional-using-the-battery-pack-b8f42f1d.jpg)

screw the board back onto the robot. 

Now, you can charge the battery pack by connecting the robot to a charger or USB port using the USB cable. While charging, the robot will show a red light. When charging is complete, the light will turn green.

> **Tip**
>
> Please do not attempt to charge the robot while it is using the 4 x AA batteries.

![Charging. Notice the red LED.](images/optional-using-the-battery-pack-9d9b2d0d.jpg)

![Charging complete. Note the green LED.](images/optional-using-the-battery-pack-b758c100.jpg)
